# beyondcy-dash

The marketing dashboard for **dash.beyondcy.co**. In this release it is only a "Stay tuned" page (no login form, no data). The page is `noindex, nofollow`.

- `index.html`: the whole page (inline CSS, no build). To change the copy, edit the block marked `<!-- COPY -->`.
- `logo-beyondcy.png` (the logo, made for dark backgrounds) and the favicons `favicon.ico`, `favicon-32.png`, `favicon-16.png`, `apple-touch-icon.png` (update v2).
- `CNAME`: `dash.beyondcy.co`.

**Deploy:** Settings → Pages → Source: *Deploy from a branch* → `main` / root. Then set the custom domain to `dash.beyondcy.co` and tick **Enforce HTTPS** once the certificate is issued.
